## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vendor result and snapshot data -> stick | Paths and hashes produced elsewhere decide where files are written on a removable volume |
| builder PC -> removable volume | The only destructive actions are a label change, READY handling and (opt-in) deletion inside closed folders |
| manifest -> anyone who reads the stick | The manifest travels with the stick and is read on laptops |

## STRIDE Threat Register

Threat IDs are unique within the phase: Plan 02-01 used T-2-01 to T-2-04 and Plan 02-02 used T-2-05 to T-2-07; this plan numbers T-2-08 onward.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-08 | Tampering | Publish-FirmwareStage target | high | mitigate | Test-FirmwareTarget refuses a non-FAT32 volume or a non-root path before any write and names the volume; the module never formats; tests cover NTFS and non-root |
| T-2-09 | Tampering | entry and snapshot paths written under the stick root | high | mitigate | Every RelativePath passes Get-KitStagePathProblem, lies under its group folder and is compared case-insensitively; tests cover `..`, rooted, colon and outside-folder paths |
