Entries are produced for every layout group whose SourceKind the vendor resolves: BiosImage gives `<Folder>\<image name>`, FlashImage gives `<Folder>\firmware.bin` (a byte-for-byte copy of the same image; the vendor flash tool needs that name), Captured groups give nothing (the core replays them from a recorded snapshot). A `{Platform}` token in a Folder is replaced with PlatformId. Which groups are staged is decided by the core writer (Plan 02-03), not by the vendor.
