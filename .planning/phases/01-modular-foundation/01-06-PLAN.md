function Get-HPKitModel { [CmdletBinding()] [OutputType([pscustomobject])] param() }   # -> Vendor, ModelId, Name, Platform, PlatformVerified, ProfilePath
function Save-HPKitVendorPack { [CmdletBinding(SupportsShouldProcess)] param([Parameter(Mandatory)][hashtable]$ModelProfile, [AllowEmptyString()][string]$OsVer, [Parameter(Mandatory)][string]$OutputPath) }

function Save-HPKitFirmware   { [CmdletBinding(SupportsShouldProcess)] param([Parameter(Mandatory)][hashtable]$ModelProfile, [AllowEmptyString()][string]$OsVer, [Parameter(Mandatory)][string]$OutputPath) }
```

GetFirmware   -> Operation 'GetFirmware', PackagePath, OsVer, Firmware[] (Id, Name, Version, Category, ReleaseDate, Path, AutoInstall, SilentInstall{File, Arguments}, RebootRequired, Devices[], ReturnCodes), Excluded[] (Stage 'Firmware'), ToolVersions
```
